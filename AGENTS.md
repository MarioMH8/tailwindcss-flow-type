# tailwindcss-flow-type agent guide

A TypeScript Tailwind CSS v4 plugin that generates fluid responsive typography utilities with CSS `clamp()`.

- **Package manager:** Bun (`bun`)
- **Build:** `bun run build`
- **Test:** `bun run test`
- **Type-check:** `bun run typecheck`
- **Lint:** `bun run lint:fix`
